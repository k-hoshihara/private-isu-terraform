# 練習問題

AWS 上に EC2 を立てて、その上で手を動かします。

- 点数の測り方は [010_common/0020-measure.md](../010_common/0020-measure.md) に書きます。
- 番号の順に並べます。今後の練習も、ここに足していきます。

進め方の全体像:

- **0015〜0100 は、1 台に全部入った構成**で進めます。
- 0110 で、役割ごとに複数台へ分けます。
- 分けると、点数は一時的に下がります。
- 各台の CPU とメモリを使い切るまで調整すると、点数を戻して、分ける前を超えます。
- 0120 でデータベースの仕事を減らし、0130 で応答を作る処理を、0160 で読み取りの結果をメモリに覚える仕組みを、それぞれ詰めます。
- 0170 で最後に詰めます（書き込み・メモリへの記憶・受け持つ台の割り当て）。

番号の振り方:

- 番号は 10 きざみです。0015 だけが例外です。
- 0015 は、**SQL の調整を、後の調整より先に終わらせるための章**です。
- SQL ひとつで点数が大きく動くうえ、変更は 1 箇所ずつに収まります。複数台に分ける前に点数を上げておきます。
- 0110 は 4 ファイル構成です。前半: 台の確認と役割の決定 / 中盤: 分ける作業 / 後半: 仕上げと運用 / 最終: CPU・メモリを使い切る調整。

入口は [../README.md](../README.md) です。
