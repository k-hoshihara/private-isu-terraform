# 当日プロンプト: recon から config.env を埋める

本番中、Claude Code / 作業用 LLM に次を投げる。

---

ISUCON 本番中です。以下の情報収集コマンドの出力を読んで、`config.env` を埋めてください。

方針:

- リポジトリの `config.env.example` の変数名をそのまま使う
- 不明な項目は値を空欄のままにし、行末に `# 要確認: 理由` を残す
- 推測でサービス名やパスワードを確定しない。候補が複数なら列挙する
- `SERVER*_ROLE` は、mysqld がいる台を db/both、アプリ unit がいる台を app/both にする
- private-isu 用の決め打ちをせず、出力に書かれているパスを優先する

出力してほしいもの:

1. 完成した `config.env` 全文
2. 要確認の一覧（優先度つき）
3. 次に人間がサーバで叩く確認コマンド
