# 初動

サーバ上、または `ssh s1` した先で打つ。値は `config.env` にメモしてから使う。

本番の Ubuntu は回ごとに違うので、事前にラッパーへしない。  
同じ作業を何度もすると分かってから、このブロックを種に Ansible を書く。

順番: 情報収集 → SSH → Python 切替 → ツール → ログ → 権限 →（必要なら）コード吸い上げ。

## SSH（作業機 → 各台）

```bash
ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519 -C isucon-kit   # 既にあれば不要
ssh-copy-id -i ~/.ssh/id_ed25519.pub isucon@192.0.2.11

cat >> ~/.ssh/config <<'EOF'
Host s1
  HostName 192.0.2.11
  User isucon
  IdentityFile ~/.ssh/id_ed25519
  StrictHostKeyChecking accept-new
EOF
```

サーバ間も通すなら、同じ公開鍵を各台の `authorized_keys` に足す。練習で SSM だけのときはこの節を飛ばす。

## Python に切り替える

unit 名は回ごとに違う。候補を見て `APP_SERVICE` に書いてから止める。

```bash
systemctl list-unit-files --type=service | grep -Ei 'isu|python|go|ruby'
systemctl cat isu-python.service

sudo systemctl disable --now isu-ruby.service
sudo systemctl disable --now isu-go.service      # あれば
sudo systemctl enable --now isu-python.service

cd /home/isucon/private_isu/webapp/python
command -v uv >/dev/null && uv sync
# または python3 -m pip install -r requirements.txt

curl -fsS -o /dev/null -m 5 http://127.0.0.1:8080/ || \
  sudo journalctl -u isu-python.service -n 80 --no-pager
```

private-isu なら [webapp-setup/python.md](webapp-setup/python.md) でも同じ。

## 計測ツール

既にあれば入れ直さない。バージョンは Releases の latest を見て書き換える。

```bash
sudo apt-get update -y
sudo DEBIAN_FRONTEND=noninteractive apt-get install -y \
  htop sysstat git jq unzip curl ca-certificates python3-pip percona-toolkit

ALP_VERSION=1.0.21
SLP_VERSION=0.2.1
OHA_VERSION=1.12.1

if ! command -v alp >/dev/null; then
  curl -fsSL -o /tmp/alp.zip \
    "https://github.com/tkuchiki/alp/releases/download/v${ALP_VERSION}/alp_linux_amd64.zip"
  unzip -o /tmp/alp.zip -d /tmp && sudo install -m 0755 /tmp/alp /usr/local/bin/alp
fi
if ! command -v slp >/dev/null; then
  curl -fsSL -o /tmp/slp.zip \
    "https://github.com/tkuchiki/slp/releases/download/v${SLP_VERSION}/slp_linux_amd64.zip"
  unzip -o /tmp/slp.zip -d /tmp && sudo install -m 0755 /tmp/slp /usr/local/bin/slp
fi
if ! command -v oha >/dev/null; then
  curl -fsSL -o /tmp/oha \
    "https://github.com/hatoo/oha/releases/download/v${OHA_VERSION}/oha-linux-amd64"
  sudo install -m 0755 /tmp/oha /usr/local/bin/oha
fi
command -v py-spy >/dev/null || sudo python3 -m pip install py-spy
```

## ログ（nginx LTSV / MySQL slow）

入れる前に `.orig` を残す。フォーマットは `etc/nginx/ltsv.conf`。

```bash
SITE=/etc/nginx/sites-enabled/isucon
sudo test -f "${SITE}.orig" || sudo cp -a "$SITE" "${SITE}.orig"
sudo cp -a etc/nginx/ltsv.conf /etc/nginx/conf.d/00-ltsv.conf
sudo sed -i 's#access_log[^;]*;#access_log /var/log/nginx/access.log ltsv;#' "$SITE"
sudo nginx -t && sudo systemctl reload nginx
```

```bash
DROP=/etc/mysql/mysql.conf.d/99-isucon-slow.cnf
sudo mkdir -p "$(dirname "$DROP")"
sudo tee "$DROP" >/dev/null <<'EOF'
[mysqld]
slow_query_log = 1
slow_query_log_file = /var/log/mysql/mysql-slow.log
long_query_time = 0
log_queries_not_using_indexes = 0
EOF
sudo mkdir -p /var/log/mysql
sudo touch /var/log/mysql/mysql-slow.log
sudo chown mysql:mysql /var/log/mysql/mysql-slow.log || true
sudo systemctl restart mysql
```

## 権限（py-spy / ulimit）

```bash
echo 'kernel.yama.ptrace_scope = 0' | sudo tee /etc/sysctl.d/99-isucon-ptrace.conf
sudo sysctl -p /etc/sysctl.d/99-isucon-ptrace.conf

sudo tee /etc/security/limits.d/99-isucon.conf >/dev/null <<'EOF'
isucon soft nofile 65535
isucon hard nofile 65535
EOF
```

ulimit はログインし直すと効く。

## 備考

### SSH できない

```bash
ssh -v -i ~/.ssh/id_ed25519 isucon@192.0.2.11
```

- Permission denied → 運営の初期鍵で一度入り、公開鍵を `authorized_keys` に足す
- Connection timed out → IP、SG の 22、起動しているか
- 練習で SSM のみ → サーバ上で直接打つ。SSH するなら Terraform で `enable_ssh = true`

### アプリが起動しない / 切替後 502

```bash
UNIT=isu-python.service
systemctl is-active "$UNIT"
systemctl is-enabled "$UNIT"
sudo journalctl -u "$UNIT" -n 80 --no-pager
ss -lntp | grep 8080
curl -v http://127.0.0.1:8080/
```

依存なら `cd $PYTHON_DIR && uv sync`。ポートが違うなら nginx の `proxy_pass`。  
go/ruby が enabled のままなら `disable --now`。unit が複数なら `systemctl cat` で選ぶ。

### nginx -t が失敗する

```bash
sudo nginx -t
ls /etc/nginx/sites-enabled
sudo cp -a /etc/nginx/sites-enabled/isucon.orig /etc/nginx/sites-enabled/isucon
sudo nginx -t && sudo systemctl reload nginx
```

### mysqld が起きない（slow 設定の直後）

```bash
sudo journalctl -u mysql -n 80 --no-pager
sudo rm -f /etc/mysql/mysql.conf.d/99-isucon-slow.cnf
sudo systemctl restart mysql
```

### ツールが入らない

GitHub に届かないときは作業機でバイナリを取って `/usr/local/bin` へ置く。

```bash
command -v alp slp oha py-spy
```
